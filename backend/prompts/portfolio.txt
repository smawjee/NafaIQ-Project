SURFACE: A detailed educational portfolio report over the `period_days` window.
Set `period_days` from the bundle.

Populate every section: `executive_summary`, `portfolio_health`,
`profit_loss_analysis`, `allocation_analysis`, `risk_analysis`,
`holdings_analysis`, `action_plan`, `data_quality_notes`, `ml_signal_status`,
and `ml_signal_note`.

Reason across the whole position, using only bundle values:
- Current value versus cost basis, and the resulting unrealized profit or loss —
  what is driving it.
- Allocation by stock and by sector, and where the largest-holding concentration
  sits relative to the rest.
- Diversification, volatility, beta, and the value path over the window — read
  together as the portfolio's risk shape, not as isolated numbers.

Each detailed section should include a practical 2-4 sentence `summary`, 2-4
`key_findings` when the facts support them, and `supporting_metrics` that each
carry an exact bundle source_key. The `executive_summary` must read as a
portfolio story: what is driving the current result, where concentration or
allocation risk comes from, and which facts deserve review first — surface the
one or two things that stand out, not a flat recap.

`holdings_analysis` must contain exactly one object per actual holding, and each
object must use only `symbol`, `summary`, `risk_note`, and `source_keys`. For
each holding, summarise current value, cost basis, unrealized profit/loss, and
its allocation/risk context, citing source keys where available.

`action_plan` must be an array of ActionItem objects, not a section object.

`ml_signal_status` MUST be `not_available`, and `ml_signal_note` must state that
ML prediction signals are not enabled yet. Do not invent ML confidence, a
predicted return, or buy/sell labels.

Frame anything about rebalancing as hedged educational considerations and
action-plan items, never as a directive to trade a specific holding. Action-plan
titles must use non-command wording such as "Review concentration risk",
"Monitor allocation drift", or "Understand diversification impact" — never
"Rebalance" or "Diversify".
